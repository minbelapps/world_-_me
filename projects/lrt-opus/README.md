# LRT Opus

Atnaujinta 2026-11-03. **Būsena: vykdomas asmeninis projektas; sukurtas rezultatas toliau vystomas.**

## Paskirtis ir vertė

Android TV programėlė LRT Opus klausymui namų Sony Bravia televizoriuje. Pirmiausia asmeninis poreikis, kartu praktinė programavimo, dizaino, testavimo ir žmogaus bei agentų bendradarbiavimo patirtis. Galimas vėlesnis uždarbis ir viešas dalijimasis, bet mokėjimų ar parduotuvės publikavimo nelaikome jau užbaigtais.
