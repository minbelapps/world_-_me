# Projekto įrankiai

Šiame aplanke laikome agentams reikalingų įrankių aprašus ir neaktyvius konfigūracijos pavyzdžius. Diegimo aplinkos, OAuth paslaptys ir prisijungimo tokenai laikomi už Git repozitorijos ribų.

## MCP registras

| MCP | Versija | Paskirtis | Būsena (2026-11-02) |
|---|---|---|---|
| Google Workspace MCP | 2.3.0 | Bendra Drive, Docs, Sheets, Slides prieiga agentams | Vietinė aplinka įdiegta, --help patikrintas. Google OAuth ir Codex / Claude aktyvi registracija neatlikti. |

- [Google Workspace diegimas, leidimai ir likę veiksmai](mcp/google-workspace.md).
- [Claude skaitymo konfigūracijos pavyzdys](mcp/claude.example.json).
- [Codex skaitymo konfigūracijos pavyzdys](mcp/codex.example.toml).

Pavyzdžiai niekur automatiškai neprijungiami. Jie rodo tik skaitymo profilį; rašymo / redagavimo prieiga dar nepatvirtinta. Įdiegtas serveris nėra tas pats, kas veikiantis ir autentifikuotas ryšys.

## Ką užrašome apie kiekvieną įrankį

Paskirtį, šaltinį ir versiją, vietinį diegimo kelią, naudojančius agentus, teisių apimtį, paleidimo / patikrinimo veiksmus, paskutinio patikrinimo datą ir neišspręstus klausimus. Nekopijuojame paslapčių net į pavyzdžius.

MCP nesinchronizuoja projekto aplanko su Drive ir neatstoja atsarginių kopijų. PC, GitHub ir Drive kopijų tvarka bus atskiras susitarimas.
