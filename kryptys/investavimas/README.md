# Investavimas

Atnaujinta 2026-11-03. Pinigų skolinimas, rinkos ir kiti būdai, kur rizikuojama pačiais pinigais. Tyrimas nėra leidimas investuoti; investavimo sprendimus priima tik savininkas.

Akcijos ir kriptovaliutos aptartos kaip didelės rizikos sritys, kuriose komanda kol kas neturi pranašumo. Pradžiai siūloma tirti sritis, kuriose rezultatą galima patikrinti be naujų investicijų.
